# 自然生成界面可配置条件汇总

> 对应代码：`NaturalSpawnSettings.java`、`MobSpawnEditScreen.java`  
> 留空或设为“不限”表示不限制该条件。

| 条件 | 类型 | 说明 |
|------|------|------|
| 生成概率（%） | 数字 | 每次自然生成尝试的通过率，0–100 |
| 维度玩家数量 | 范围 | 维度内非旁观玩家的最小/最大数量 |
| 附近同类上限 | 数字 | 达到该数量时阻止生成 |
| 附近检测半径 | 数字 | 默认 16 方块 |
| 生成高度范围 | 范围 | Y 坐标最小/最大值 |
| 距玩家距离范围 | 范围 | 与最近玩家的距离（方块） |
| 距世界出生点范围 | 范围 | 与世界出生点的距离（方块） |
| 天空可见性 | 循环 | 不限 / 必须露天 / 必须不可见天 |
| 生成位置流体 | 循环 | 不限 / 无流体 / 水中 / 岩浆中 |
| 史莱姆区块 | 循环 | 不限 / 必须是 / 必须不是 |
| 综合光照范围 | 范围 | 0–15，包含天空光照 |
| 天空光照范围 | 范围 | 0–15 |
| 方块光照范围 | 范围 | 0–15 |
| 每日时间范围 | 范围 | 0–23999 刻 |
| 世界天数范围 | 范围 | 从第 0 天起算 |
| 月相 | 多选器 | 可切换白名单/黑名单，选择原版 8 种月相 |
| 天气 | 循环 | 不限 / 晴天 / 下雨 / 雷暴 |
| 难度 | 循环 | 不限 / 和平 / 简单 / 普通 / 困难 |
| 区域难度范围 | 范围 | 随天数和区块活跃时间增长 |
| 维度名单 | 多选器 | 可切换白名单/黑名单，选择维度 ID |
| 生物群系名单 | 多选器 | 可选择群系 ID 和群系标签 |
| 结构名单 | 多选器 | 结构 ID、标签或 `*`（任意结构） |
| 脚下方块名单 | 行编辑器 | 生物站立的方块 ID 或 `#tag` |
| 生成处方块名单 | 行编辑器 | 生物生成位置所在的方块 |
| 上方方块名单 | 行编辑器 | 生成位置正上方的方块 |

每个“名单”类条件都支持**白名单/黑名单**模式；方块名单每行一个 ID，支持 `#tag` 标签，保存时会校验方块/标签的有效性。
